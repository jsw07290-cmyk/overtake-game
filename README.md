# REDLINE — 무한 역주행

충돌할 때까지 점수를 쌓는 4차선 아케이드 게임. 시간 제한은 없습니다.
`REDLINE.html` 하나를 Chrome/Edge에서 열면 됩니다. 이미지·CSS·JavaScript가 모두 포함되어 있습니다.
`REDLINE-hard.html`은 하드 모드가 선택된 버전이며 시작 화면에서 일반/하드를 바꿀 수 있습니다.

개발 서버: 이 폴더에서 `python3 -m http.server 8000 --bind 127.0.0.1`.
원본 소스를 정적 호스팅할 때는 index.html, style.css, game.js, assets/를 함께 올리세요.
단일 HTML 재생성: `python3 tools/build.py` (Python 표준 라이브러리만 사용).

- ←/→ 또는 A/D: 차선 이동. ↑/W 가속, ↓/S 브레이크 (브레이크 우선).
- Enter/Space: 시작·재시작·재개. Esc: 일시정지/재개. 탭 이탈 시 자동 정지.
- 모바일: 하단 다중 포인터 버튼. 사운드는 시작 입력 후 활성화되며 음소거 설정을 저장합니다.

## GitHub에서 내려받기

1. [REDLINE.html 파일](https://github.com/jsw07290-cmyk/overtake-game/blob/main/REDLINE.html)을 엽니다.
2. 파일 화면 오른쪽 위의 **Download raw file (↓)** 버튼을 누릅니다. GitHub 화면 안에서는 게임이 실행되지 않습니다.
3. 내려받은 **REDLINE.html**을 Edge, Safari, Firefox 등 웹 브라우저로 엽니다. 별도 압축 해제나 설치가 필요 없습니다.
4. 파일 다운로드 버튼을 찾기 어렵다면 저장소의 **Code → Download ZIP**을 누르고, 압축을 푼 폴더에서 **REDLINE.html**을 엽니다.

하드 모드가 기본 선택된 파일은 **REDLINE-hard.html**입니다. REDLINE.html 시작 화면에서도 모드를 바꿀 수 있습니다.

## 점수와 아이템

통과 기본 100 + 근접 회피 100~300, 속도 배율 ×1/×2/×3/×5, 연속 근접 콤보 최대 +40%.
근접 당시 속도로 판정하고 안전하게 통과한 뒤 한 번만 확정합니다.
차량 운반 트레일러에 200km/h 이상 가속 진입하면 점프합니다. 공중 조작이 가능하며 착지 보정·충돌 보호는 없습니다.
트레일러는 이전 출현 기회 대비 30% 확률로 생성되며, 접촉한 상대 차는 튕겨 나갑니다.

금색 코인:
- **TANK**: 군인 캐릭터의 따봉 코인. 4초 동안 탱크로 변신해 앞 차량을 밀어버립니다.
- **FLY ×2**: 눈에 검은 사각형이 덧붙은 머스크풍 인물의 따봉 코인. 은색 비행 자동차로 변신해 2.6초 동안 2배 이동 속도로 날고 착지합니다.
- 코인 획득 시 0.65초 동안 중앙으로 확대·회전한 뒤 차량으로 돌아오는 연출을 표시합니다. 한 판에 총 2~3개만 등장하며, 놓친 코인은 보충하지 않습니다. 첫 코인과 다음 코인 간격은 최고속도(315km/h)로 약 15초에 해당하는 1,312.5m입니다.
- 획득 연출과 아이템 지속 시간은 주행 시간에 포함되지 않습니다. 아이템 중 추가 근접 보너스를 주지 않습니다.
- 아이템 종료 즉시 일반 충돌 판정으로 돌아갑니다. 정지 중에는 아이템 시간도 멈춥니다.

HARD는 상대 차량의 실제 접근 속도가 일반 대비 1.5배입니다. 조작 반응은 같고 모드별 TOP 3는 따로 저장합니다.
무한 모드 기록은 기존 30초 모드 기록과 별도 키에 보관합니다. 닉네임 수정·동점·저장 실패를 처리합니다.
충돌 시 차체 회전, 파편, 스파크, 연기와 충격음 뒤에 결과를 표시합니다.

검증: `node tests/game.test.cjs` (25개 테스트). 설정은 game.js 상단 CFG에 모여 있습니다.
기존 원본 `overtake-game.zip`과 이전 일반 개선판 `REDLINE-improved.html`은 보존했습니다.
